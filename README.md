# Моя библиотека

React-приложение для управления личной библиотекой книг. Позволяет добавлять книги, отслеживать прогресс чтения, выставлять рейтинги и настраивать отображение карточек.

## Стек

- **React 19** + **TypeScript 6**
- **Vite 8** - сборка и dev-сервер
- **React Router v7** - маршрутизация
- **Zustand** - управление состоянием
- **Tailwind CSS v4** - стилизация
- **PWA** - поддержка офлайн-режима

## Быстрый старт

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

## Команды

| Команда           | Описание                     |
| ----------------- | ---------------------------- |
| `npm run dev`     | Запустить dev-сервер         |
| `npm run build`   | Собрать продакшен-билд       |
| `npm run preview` | Предпросмотр продакшен-билда |

## Структура проекта

```
src/
├── app/          # Точка входа, роутер, layout
├── pages/        # Страницы: список книг, добавление, редактирование, настройки
├── components/   # Компоненты: карточки, формы, шапка
├── shared/       # Общие модули: UI-компоненты, хуки, провайдеры, константы, типы
└── styles/       # Tailwind-конфиг и глобальные стили
```

## Функциональность

- Добавление и редактирование книг
- Фильтрация по статусу (читаю / новая / прочитано)
- Рейтинги и прогресс чтения
- Настраиваемые карточки: выбор отображаемых элементов, компактный режим
- Тёмная и светлая тема
- Поиск по библиотеке
- Предпросмотр карточки в настройках в реальном времени
